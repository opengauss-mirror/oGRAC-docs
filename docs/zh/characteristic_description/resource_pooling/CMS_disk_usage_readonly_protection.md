# CMS磁盘阈值管理检测

## 可获得性<a name="section3480125215575"></a>

本特性自oGRAC版本开始引入。

## 特性简介<a name="section5814521587"></a>

CMS磁盘阈值管理检测用于对数据库本地数据目录和DSS共享存储VG进行周期性容量采集，并基于统一阈值判断磁盘使用率风险。

## 客户价值<a name="section148987345811"></a>

本特性能够在磁盘使用率达到阈值时自动触发数据库切换为只读模式，避免磁盘持续写满导致实例异常、日志写入失败或业务数据风险。

## 特性描述<a name="section117041846581"></a>

oGRAC新增CM磁盘阈值管理能力，支持由CMS对数据库本地数据目录和DSS共享存储VG进行周期性容量采集，并基于统一阈值判断磁盘使用率风险。当本地磁盘或DSS VG使用率达到配置阈值时，CMS可自动触发数据库切换为只读模式；当磁盘使用率恢复到阈值以下后，CMS可在冷却时间控制下自动恢复数据库读写状态。该特性提供统一的`cms diskreadonly`管理命令，支持查看当前磁盘使用率、阈值配置、自动只读保护状态，以及在线调整阈值、采集间隔、冷却时间和自动保护开关。配置项写入`cms.ini`后持久生效，CMS后台任务会按配置周期持续采集并执行保护逻辑。

## 特性增强<a name="section21149265913"></a>

无。

## 特性约束<a name="section51513617597"></a>

仅适用于CMS已部署且可正常采集本地文件系统与DSS信息的场景。

## 依赖关系<a name="section20491151513592"></a>

依赖CMS管理组件和数据库本地存储、DSS共享存储的正常可达性。
