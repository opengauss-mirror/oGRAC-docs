# 常见故障恢复问题

本模块汇总 oGRAC 在 **编译、安装、运行、卸载** 各阶段中常见的稳定性问题，并给出对应的 **定位思路与解决方案**，帮助在出现故障时快速判断问题类型、缩小排查范围。

## 问题阶段分类

请根据故障发生的阶段选择对应目录查看：

- [编译阶段问题](./issues_during_the_compilation_phase/index.md)：覆盖 oGRAC 编译过程中因 `gcc` 版本、三方库、缺少依赖组件等导致的编译失败问题。
- [安装阶段问题](./issues_during_the_installation_phase/index.md)：覆盖 oGRAC 安装部署过程中因环境配置、共享存储（`LUN`、`CM` 投票盘、`DSS`）、节点时间同步等导致的安装失败问题，并提供对应问题的定位入口。
- [运行阶段问题](./issues_during_the_running_phase/index.md)：覆盖 oGRAC 运行过程中因系统资源（如内存）不足等导致的运行失败问题。
- [卸载阶段问题](./issues_during_the_uninstallation_phase/index.md)：覆盖 oGRAC 卸载过程中因进程残留、共享存储残留等导致的卸载失败问题。

## 通用排查建议

在定位任何问题时，建议遵循以下排查顺序：

1. 优先查看安装与运行日志，明确失败阶段。
2. 判断是否涉及共享 `LUN` 或 `CM`/`DSS` 组件。
3. 必要时保留二进制进行辅助分析。
4. 确认共享盘注册状态与软链接一致性。
