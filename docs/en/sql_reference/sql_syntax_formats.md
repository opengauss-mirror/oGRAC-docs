# SQL Syntax Formats

<!-- md-trans-meta sourceCommit=unknown translatedAt=2026-07-30T12:16:46.069Z pushedAt=2026-08-17T09:52:11.845Z -->

**Table 1** SQL syntax formats

| Format  | Meaning  |
| :------------ | :------------ |
| []  | Bracketed content is optional. |
| ...  | The preceding element may be repeated. |
| [ x \| y \| ... ]  | Choose one option or none from two or more options. |
| { x \| y \| ... }  | Choose exactly one option. |
| [ x \| y \| ... ] [ ... ]  | Choose zero or more options, separated by spaces. |
| [ x \| y \| ... ] [ ,... ]  | Choose zero or more options, separated by commas. |
| { x \| y \| ... } [ ... ]  | Choose one or more options, separated by spaces. |
| { x \| y \| ... } [ ,... ]  | Choose one or more options, separated by commas. |
